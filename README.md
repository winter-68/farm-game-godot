# Project Sprout

Project Sprout is a small cozy farming game made with Godot.

## Download and Play

Download the Windows build here:

[ProjectSprout-Windows.zip](downloads/ProjectSprout-Windows.zip)

After downloading:

1. Unzip the file.
2. Run `ProjectSprout.exe`.
3. If Windows shows a security warning, choose "More info" and then "Run anyway".

## Controls

- Move: `WASD`
- Use tool: `J` or left mouse button
- Harvest: `Space`
- Interact / draw water / enter buildings: `E`
- Inventory: `Tab`
- Shop: `B`
- Collection: `C`
- Sleep: `Enter`
- Pause: `Esc`
