# Project Sprout Assets

`assets/` 用于存放后期正式美术素材。当前阶段仍以 Godot 内的占位色块和 `.tres` 数据为主，本目录先建立素材交付规范，不引入外部图片、音频或第三方插件。

推荐目录结构：

```text
assets/
  sprites/
    characters/
      player/
      npcs/
    portraits/
    crops/
    items/
    fish/
    food/
    tiles/
    buildings/
    weather/
  ui/
    icons/
    panels/
  source/
    aseprite/
    references/
```

正式素材规范见：

```text
docs/ART_GUIDE.md
```
