# 游戏设计文档（GDD）— Project Sprout

## 1. 一句话定位

一款原创 2D 像素风单人农场经营游戏：玩家在一小块农场上翻地、播种、浇水、等待作物成长、收获并出售换取金币，循环推进。

> 玩法灵感来自农场经营品类，但**角色、美术、剧情、地图、UI、音乐、具体设定均为原创**，不复用任何现有作品内容。

## 2. 设计支柱（Design Pillars）

1. **可循环的正反馈**：种下 → 照料 → 收获 → 卖钱 → 再投资，闭环短、上手快。
2. **网格化的清晰操作**：所有农事都在瓦片网格上进行，因果关系直观。
3. **可扩展的干净架构**：MVP 只做核心循环，但每个系统都为后续（NPC、季节、矿洞等）留接口。

## 3. 目标平台 / 规格

- 平台：PC（Windows 优先），键鼠操作。
- 视角：俯视 2.5D（top-down），角色 4 方向。
- 像素：基础瓦片 `16×16`，游戏内整数缩放（基础视口 `320×180`），保证像素清晰。

## 4. 核心玩法循环（MVP）

```
起床(新的一天) → 查看农田状态(作物是否成熟/需浇水)
   → 用锄头翻地 → 选种子播种 → 浇水
   → 移动/探索 → 收获成熟作物 → 到商店出售
   → 睡觉 → 时间推进到下一天，作物按浇水情况成长
```

## 5. MVP 功能范围（In Scope）

| # | 功能 | 描述 |
|---|------|------|
| 1 | 玩家移动 | 4 方向移动，面朝方向决定「目标瓦片」 |
| 2 | 农田系统 | 网格瓦片，记录每格状态（是否翻耕/浇水/有作物） |
| 3 | 翻地 | 对目标瓦片使用锄头 → 变为耕地 |
| 4 | 播种 | 在耕地上消耗一颗种子 → 生成作物（阶段0） |
| 5 | 浇水 | 对有作物的耕地浇水 → 当天标记为「已浇水」 |
| 6 | 作物成长 | 跨天时，若前一天已浇水则推进一个成长阶段 |
| 7 | 收获 | 对成熟作物交互 → 产出物进背包，作物消失（或可再生） |
| 8 | 背包 | 存储种子/产出物，容量有限，可选中一格 |
| 9 | 出售作物 | 商店界面卖出产出物换金币 |
| 10 | 金币系统 | 全局货币，增减有信号广播 |
| 11 | 时间系统 | 分钟/小时/天推进，睡觉进入下一天 |
| 12 | 存档系统 | 保存/读取全部状态（JSON 存到 `user://`） |

## 6. 明确排除（Out of Scope，第一阶段不做）

NPC / 对话 / 好感度 / 结婚、矿洞 / 战斗、钓鱼、节日、主线剧情、季节与复杂天气、烹饪 / 制作台、动物、多存档槽的复杂管理、联网 / 多人。

> 架构会为「季节」「多物品类型」「工具升级」预留字段，后续扩展改动成本低。

## 7. 占位美术规范（Placeholder Art）

- 全部用**纯色方块 / 简单色块**当占位：
  - 玩家：`24×24` 蓝色方块（含一个朝向指示小块）。
  - 地面：绿色 `16×16` 瓦片；耕地：棕色；浇水后耕地：深棕色。
  - 作物：按成长阶段用不同高度/颜色的小方块（阶段 0 小、成熟大）。
- 命名统一，后续替换正式美术时**只换资源、不改逻辑**。
- 音频 MVP 不做。

## 8. 输入约定（Input Map，MVP）

| 动作名 | 默认键 | 用途 |
|--------|--------|------|
| `move_up/down/left/right` | W A S D | 移动 |
| `interact` | 空格 / E | 收获、确认、与商店/床交互 |
| `use_tool` | 鼠标左键 / J | 对目标瓦片使用当前工具/物品（翻地/浇水/播种） |
| `hotbar_1..hotbar_0` | 数字键 1~0 | 选择背包快捷栏 |
| `toggle_inventory` | I / Tab | 开关背包 |

## 9. 首个可玩里程碑（Vertical Slice 验收）

> 能在 30 秒内完成：走到地里 → 翻一格 → 种一颗 → 浇水 → 睡觉 → 看到作物长大 → 再睡两天收获 → 卖钱 → 金币增加 → 退出重进存档还在。
