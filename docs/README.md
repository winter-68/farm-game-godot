# Project Sprout — 规划文档索引

原创 2D 像素风农场经营游戏（Godot 4.3+ / GDScript）。本目录是项目的**策划与技术蓝图**，供人类与 Codex 共同参考。

> 代号 `Project Sprout` 为临时名，代码统一使用 `sprout` 命名。引擎按 **Godot 4.3+** 设计（使用 `TileMapLayer`）。

## 开发约定（所有任务共同遵守）

- 引擎 **Godot 4.3+**，语言 **GDScript**，缩进用 Tab。
- 每个任务**只创建/修改该任务卡列出的文件**，其余不动。
- 全部使用占位色块，不引入外部美术/音频资源。
- 代码需在 Godot 编辑器中无报错运行；公有方法写简短注释。
- 不擅自新增第三方插件。
- **一次只做一个任务**，做完在 Godot 中按「测试步骤」验收通过后再进下一个。

## 推进顺序

1. 按 `tasks/` 中 **T0 → T1 → … 顺序**逐个交给 Codex。
2. 每个任务完成后在 Godot 内验收。
3. T0–T5 跑通后，补充批次 B（T6–T11）任务卡。
