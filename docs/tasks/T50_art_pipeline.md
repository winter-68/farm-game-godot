# T50：美术规格与素材替换流程

## 目标

为 Project Sprout 建立后期美术素材的尺寸、命名、目录和替换流程规范，避免正式美术进入项目后出现尺寸混乱、命名不统一、导入设置不一致的问题。

## 实现要求

1. 新增 `docs/ART_GUIDE.md`
   - 定义整体像素风格方向。
   - 定义主角、NPC、头像、物品图标、作物、鱼、料理、TileSet、天气特效的推荐尺寸。
   - 定义文件命名规则。
   - 定义 Godot 导入设置。
   - 定义从占位色块替换为正式素材的流程。

2. 新增 `assets/README.md`
   - 说明 `assets/` 是未来正式素材目录。
   - 说明当前阶段不放外部素材，只建立目录规范。
   - 列出推荐子目录。

3. 更新 `docs/BACKLOG.md`
   - 记录 T50 已完成。

## 验收

- 能从文档直接看出后期人物外貌、头像、物品、地图瓦片应该用什么尺寸。
- 能从文档直接看出素材文件应该怎么命名。
- 能从文档直接看出素材替换时在 Godot 里应该如何设置导入选项。
- 没有新增外部图片、音频或第三方插件。
