# T52：背包 / 快捷栏 / 商店图标显示

## 目标

让主要物品 UI 支持显示 `ItemData.icon`。当正式图标缺失时，使用 T51 的占位图标，保证 UI 不崩溃、不空白。

## 实现

1. 快捷栏
   - 每个槽位显示 16×16 图标。
   - 图标下方保留物品名和数量。
   - 选中高亮逻辑保持不变。

2. 背包
   - 每个格子显示 16×16 图标。
   - 图标下方保留物品名和数量。
   - 料理点击食用逻辑保持不变。

3. 商店
   - 出售行显示物品图标。
   - 购买行显示物品图标。
   - 鱼竿购买行显示物品图标，并保留等级限制。

## 验收

- 没有正式 icon 时，背包 / 快捷栏 / 商店显示占位图标。
- 后续给 `ItemData.icon` 填入正式图片后，UI 自动显示正式图标。
- 背包料理点击食用、快捷栏切换、商店买卖逻辑不受影响。
- 不新增外部图片、音频或第三方插件。
