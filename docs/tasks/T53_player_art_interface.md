# T53：主角正式美术接口

## 目标

让 Player 支持未来的 4 向站立 / 4 向行走贴图。当前没有正式素材时，继续显示安全占位小人，不影响移动、朝向、交互。

## 实现

1. 新增 `PlayerArtData`
   - 4 向站立贴图：down / up / left / right。
   - 4 向行走帧数组：down / up / left / right。
   - 占位颜色。
   - 行走帧时间。

2. 新增默认资源
   - `resources/player_art_default.tres`
   - 当前只保存占位色和帧时间，不引入外部图片。

3. 更新 Player
   - 导出 `art_data`。
   - 移动时按当前朝向播放行走帧。
   - 停下时显示对应方向站立图。
   - 缺失贴图时使用占位小人。

## 验收

- 没有正式贴图时，玩家仍可正常移动。
- 停下后朝向仍保持最后方向。
- 后续给 `PlayerArtData` 填入正式贴图后，不需要改逻辑代码即可显示。
- 不新增外部图片、音频或第三方插件。
