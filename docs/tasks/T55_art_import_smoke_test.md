# T55：美术导入链路冒烟测试

## 目标

用项目内原创的极简像素 PNG 验证正式美术替换链路：PNG 放入 `assets/`，绑定到 `.tres`，由 Player / UI 自动显示。

## 实现

1. 新增测试 PNG
   - 主角 4 向站立。
   - 主角 4 向行走，每方向 2 帧。
   - 少量核心物品图标：锄头、水壶、绿豆种子、绿豆、鲤鱼、烤土豆、基础鱼饵。

2. 绑定资源
   - `resources/player_art_default.tres` 绑定主角贴图。
   - 对应 `resources/items/*.tres` 绑定 `icon`。

3. 保持约束
   - 所有 PNG 都是项目内生成的原创测试图。
   - 不引入外部美术、音频或第三方插件。

## 验收

- Player 不再只是纯色块，而是显示测试像素小人。
- 快捷栏 / 背包 / 商店中已绑定的物品显示测试图标。
- 未绑定 icon 的物品继续显示占位图标。
- Godot 加载无红色报错。
