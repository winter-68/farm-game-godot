# T81：角色透明切图修复

## 目标

修复导入主角/NPC 素材后，人物在部分朝向或行走帧中出现半透明、镂空、闪烁的问题。

## 问题原因

早期素材切图时按背景颜色做透明处理，误把角色衣服、皮肤、头发边缘里的浅色像素也扣掉了，导致人物内部出现透明洞。左向帧相对完整，所以表现成“只有向左走是实心”。

## 实现

1. 重新裁切主角运行时 Sprite 帧。
2. 重新裁切 NPC 运行时 Sprite 帧。
3. 透明处理改为只移除外部连通背景。
4. 填回角色轮廓内部被误删的透明空洞。
5. 输出统一为 32×48 像素，alpha 只保留 0/255，避免半透明边缘。

## 验收

- 主角上下左右站立/移动时不再透明。
- 主角行走不再因透明洞产生闪烁。
- NPC 上下左右移动帧不再透明。
- Godot 导入资源无报错。
- 主场景可正常加载。
